# ADR R02-02-175 — Readiness observacional separado de autorización

**Estado:** ACCEPTED_FOR_R02_02_ONLY. **Base:** `4a4443f1631acdbfcd19e1e2fca4be36f707daf9`.

**Contexto.** Los adapters Ollama/LM Studio y su política loopback existen; Settings mostraba diagnóstico estático pero no cinco estados por tarea ni health opt-in explícito.

**Decisión.** Reutilizar `LocalProviderDiscoveryService` y `LocalEndpointPolicy`. Proyección read-only al cargar Configuración; POST explicit owner-session/CSRF/RBAC para GET internos loopback acotados, máximo 2 segundos por proveedor. Recursos medidos exclusivamente desde OS; RAM/CPU si disponibles; GPU/VRAM no inferidos. Readiness por tarea permanece no-evaluado hasta datasets reales de R02-03+.

**Autoridad.** Health != eligibility, enabled != configured, settings preference != runtime enablement. Sin prompts, tokens, egress cloud ni escritura. Se incorpora catálogo RBAC, contrato API y OpenAPI estático. Fallo del proveedor no bloquea ruta mock.

**Consecuencias.** Browser explícito para acreditar consentimiento y verificar 375px; sin modelos locales instalados se acepta el estado `NOT_TESTED` con limitaciones. Coste remoto 0, coste local hardware no valorado económicamente.
