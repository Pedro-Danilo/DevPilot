# ADR R01-03 — Negociación offline separada del router ejecutivo

## Contexto
El baseline ya define `ModelAdapter` (ABC), `MockModelAdapter`, `ModelCapabilityCatalog`, `ModelRouterV2`, políticas de endpoint y adapters Ollama/LM Studio. Falta un contrato aislado para distinguir soporte declarado, configuración, salud, evaluación y elegibilidad sin presuponer servidor local.

## Decisión
Se añade `OfflineCapabilityNegotiator` sobre los contratos existentes sin sustituir `ModelRouterV2`; mock ejecutable determinista y `LocalStubModelAdapter` **no ejecutable**. Se deniega API externa, endpoint no loopback, clave secreta local, fallback silencioso, tools/streaming no declarados, timeout fuera del máximo, provider desconocido y local sin evaluación. La ausencia de health/evals nunca se infiere como PASS.

## Consecuencias
El nuevo contrato es de nivel servicio/mock y no acredita readiness de modelos locales reales. R01-04 integra routing/policy/budgets; R2 realiza salud/evaluación real. No se modifica UI, no se habilita egress ni MP-1B. La ADR queda como candidata en bundle, sin publicar un path extra no aprobado.
