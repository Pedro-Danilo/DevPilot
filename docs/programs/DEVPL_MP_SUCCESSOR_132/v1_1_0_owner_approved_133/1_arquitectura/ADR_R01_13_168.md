# ADR R01-13: WorkflowStatusProjection derivada, sin nueva autoridad

**Estado:** propuesta para adopción en el cierre Windows.

## Contexto
La vista de Project Status calcula un estado visual y una siguiente acción desde overlays de lifecycle, Pre-code y Planning. Esto permite representar READY en la UI mientras el NextAction autorizado está pendiente, o habilitar CTAs por lógica divergente.

## Decisión
Crear `project_workflow_status` como proyección pura y fail-closed, calculada solo después de la reconciliación actual del servicio. El mismo objeto se publica en el payload existente `guided_sdlc.project_status`, sin endpoint nuevo. Encabezado, panel y CTA consumen ese resultado. El avance terminal nunca es una escritura desde esta vista.

## Riesgos y límites
No sustituye el WorkflowEngine ni actualiza estados; depende de que las fuentes de ProjectStatus/NextAction sigan autoritativas y actualizadas. En discrepancia o ausencia, los CTAs quedan inhabilitados. Requiere pruebas browser Windows antes de publicación remota.
