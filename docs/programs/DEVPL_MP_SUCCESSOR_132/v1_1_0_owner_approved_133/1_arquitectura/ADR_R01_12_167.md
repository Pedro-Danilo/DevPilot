# ADR R01-12-167 — Proyección de observabilidad de lista blanca

**Estado:** ADOPTADA PARA CANDIDATO / aceptación Windows pendiente.

**Contexto:** el runtime ya emite recibos y hashes; el componente de UI mostraba JSON amplio y podía presentar importes desconocidos como cero. Una segunda autoridad de métricas crearía divergencias.

**Decisión:** derivar la visualización del sobre `GenerationProvenanceEnvelope` y `ProviderExecutionReceipt` por enlace SHA, sin aceptar metadatos arbitrarios. Mostrar en Guided campos limitados; en Expert, proyección redactada y hashes, no payloads completos. Para estimaciones o ausencia de medición emitir `NOT_AVAILABLE`. Sólo vista previa determinista, sin ejecución efectiva, puede justificar costo API 0; se indica su clasificación. Trazas selladas de agentes conservan su origen y costo desconocido explícito. El provider runtime no gana permiso de herramienta.

**Consecuencias:** reutilización de contratos, menor exposición accidental, ninguna API/clave/red nueva, UI más trazable; no acredita inferencia local/external, mediciones de latencia/costo reales, ni calidad de un proveedor. Un servicio de telemetría persistente real correspondería a una evolución posterior autorizada.
