# ADR — Logical Project Layout as a read-only projection

**Estado:** PROPOSED-for-R01-14 / Owner implementation approved

**Contexto:** GSDLC-13-B/C ya soporta greenfield neutral con bootstrap governance; crear un segundo generador físico duplicaría autoridad y expondría drift.

**Decisión:** ProjectLayoutPlanner consume solo ProjectIntake v2 validado y BootstrapPlan íntegro y hash-bound. Devuelve zonas lógicas, technology `PENDING_ARCHITECTURE`, documentos `LAZY_GOVERNED` y scaffold `NOT_AUTHORIZED`. No muta workspaces ni crea archivos. Integration por planning facade existente.

**Seguridad:** rechaza rutas con traversal, rutas absolutas, escapes, enlaces simbólicos, perfiles tecnológicos prematuros, redes y dependencias anticipadas. El executor histórico sigue siendo el único autorizado para bootstrap real.

**Trade-off:** primera vertical es service/planning, no UI. La producción de contenido documental lazily gobernado sigue con autoridad del servicio de publicación, no con la proyección.
