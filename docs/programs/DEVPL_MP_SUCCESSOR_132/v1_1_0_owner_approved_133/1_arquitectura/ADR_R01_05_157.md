# ADR R01-05 — PESP v2 por proyecto sobre catálogo único

Estado: **PROPOSED / NO PUBLICADA**. Fecha: 2026-10-15.

## Contexto
DevPilot posee `StandardsRegistry` y `ArtifactProfileRegistry` con reglas estructurales Markdown. La aplicabilidad debe depender de componentes reales del producto y evidencia, no de que DevPilot use LLM como herramienta de desarrollo.

## Decisión
Implementar evaluación determinista por proyecto `ProjectFacts → ProjectApplicability`, accesible desde `ArtifactProfileRegistry`. MIPSoftware siempre REQUIRED; MIASI REQUIRED con IA del producto confirmada, NOT_APPLICABLE con evidencia negativa o REVIEW_REQUIRED ante desconocidos. AI tool-write requiere Agent/Tool/Human Approval Cards. Waivers documentan REVISIÓN, no pasan controles legal/seguridad ni sustituyen aprobación. FROZEN es inmutable; successor enlaza hash/revisión de antecedente.

## Consecuencias
Reuso del único catálogo, no se altera selección histórica. Sin motor de ejecución o publicación, sin persistencia de perfiles (posterior), no se concede autoridad normativa ni egress. Coverage Gate completo corresponde a R01-06.
